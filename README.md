# IT Helpdesk Ticket Tracker

## About the Project

A beginner-friendly JavaScript application that identifies IT support tickets requiring attention.

This project was created as part of my Introduction to Programming capstone through We Can Code IT.

## Features

- Stores fictional IT support tickets in an array of objects.
- Identifies tickets with Open or Pending status.
- Excludes Closed tickets.
- Displays ticket numbers, issues, priorities, and statuses.
- Counts the total number of tickets needing attention.

## Technologies Used

- JavaScript
- CodePen
- GitHub

## How to Run

1. Download or clone this repository.
2. Open `script.js` in a JavaScript environment, such as CodePen's JavaScript editor.
3. Run the code and view the output in the console.

## Example Output

```text
Ticket #1001 | Wi-Fi connection issue | High | Open
Ticket #1003 | Printer not responding | Medium | Pending
Ticket #1004 | VPN connection failure | High | Open
3 tickets need attention.
```
